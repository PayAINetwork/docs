## Welcome to PayAI

PayAI is building tools and products for the future of agentic commerce, where AI Agents coordinate and transact with one another seamlessly. 

Our open-source technologies empower developers to create and monetize AI agents and services.

Use the guides below to choose an integration and check its operating requirements.

## Start with your task

| You want to | Start here |
| --- | --- |
| Try an end-to-end payment example | [x402 quickstart](/x402/quickstart) |
| Charge for an API or resource | [Merchant integration guides](/x402/servers/introduction) |
| Pay for an API or resource | [Client integration guides](/x402/clients/introduction) |
| Understand PayAI's verification and settlement role | [Facilitator introduction](/x402/facilitators/introduction) |
| Use metered Solana channels and vouchers | [Batch settlement public preview](/x402/servers/batch-settlement) |

Before production, check [pricing](/x402/facilitators/pricing), [server authentication](/x402/facilitators/authentication), [supported networks](/x402/supported-networks), and [capacity and recovery](/x402/facilitators/capacity-and-limits).
