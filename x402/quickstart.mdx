This page gets you set up quickly as a merchant (server) or a buyer (client).

If your goal is to let AI agents pay for an API or SaaS operation, start with [Accept payments from AI agents](/guides/accept-payments-from-ai-agents) for the end-to-end path.

For a complete Mainnet merchant and guarded buyer, choose [Base Express](/x402/base-mainnet-express) with upstream `@x402/evm` or [Solana Express](/x402/solana-mainnet-express) with `@x402/svm`.

Choose your language and framework below to get started.

## Facilitator

The TypeScript guides use `@payai/facilitator`, which automatically connects to the PayAI facilitator at `https://facilitator.payai.network`. No manual URL configuration needed.

```typescript
import { facilitator } from "@payai/facilitator";
import { HTTPFacilitatorClient } from "@x402/core/server";

const facilitatorClient = new HTTPFacilitatorClient(facilitator);
```

The facilitator works immediately for ordinary exact payments, including mainnet production traffic within the [free allowance](/x402/facilitators/pricing). No API key or portal signup is required to launch. When you need paid capacity beyond the allowance, an autonomous agent can [buy credits and receive an API key over x402](/x402/facilitators/agent-api-keys); the paying wallet gets a wallet-owned agent account programmatically. You can also use the optional [merchant dashboard](https://merchant.payai.network). Then set `PAYAI_API_KEY_ID` and `PAYAI_API_KEY_SECRET` to authenticate.

The PayAI facilitator supports the following endpoints:

- `/supported` - see which networks and schemes are supported
- `/verify` - verify that a payment is valid
- `/settle` - settle the payment
- `/discovery/resources` - view the bazaar, a marketplace of merchants

Read the [reference](/x402/reference#7-1-post-%2Fverify) for more information on the facilitator endpoints and responses.
