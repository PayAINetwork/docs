## What a payment costs

One credit is $0.001. Each payment your server settles costs its network's rate in credits. The rate tracks the on-chain gas PayAI pays to settle on that network, plus 30%, and refreshes daily. It is never a percentage of the payment amount. Testnets are free.

For example, if the Solana rate is 1.33 credits:

| Payments | Credits | Cost |
|---|---:|---:|
| 1 | 1.33 | $0.00133 |
| 1,000 | 1,330 | $1.33 |
| 100,000 | 133,000 | $133 |

Rates differ by network and change with gas prices. See the [live rates](https://facilitator.payai.network/pricing) for every network.

Batch settlement and `upto` are priced per on-chain transaction, so a channel costs the sum of its legs (deposit, claim, refund and so on). Solana token-account (ATA) setup is a separate cost. Enterprise (invoiced) accounts use the same rates unless their agreement says otherwise.

<Note>
  The facilitator fee is separate from the price your API charges its customer.
  Payment amounts must satisfy the advertised payment requirements and the
  selected scheme's rules. Batch channel deposits have their own
  [limits](/x402/servers/batch-settlement); they are not the price of each API request.
</Note>

### Reading rates from your server

`GET /supported` carries the current rates under `pricing`, so a server can read the price for the network it is about to use. `GET https://facilitator.payai.network/pricing` returns the same object when you request JSON (`Accept: application/json`), including any upcoming change and its effective time.

```json
{
  "creditUsd": "0.001",
  "marginBps": 3000,
  "rates": [
    { "network": "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp", "scheme": "exact",
      "transferMethod": "svm_transfer", "credits": "1.33", "usd": "0.00133",
      "effectiveAt": "2026-10-15T12:00:00.002Z" }
  ],
  "upcoming": []
}
```

## Buying credits

Agents can [buy credits and receive an API key over x402](/x402/facilitators/agent-api-keys), with no portal signup. PayAI creates a wallet-owned agent account during the purchase. A paying wallet already linked to a portal account receives credits but not a new agent key; manage that account's keys in the portal. People can use the optional [merchant dashboard](https://merchant.payai.network/?payai_campaign=docs-pricing).

Credits never expire. Paying with `$PAYAI` on Solana gets a 10% discount; review the quote before you pay. Your customers do not need `$PAYAI` to pay your API in USDC.

Add your API key to your server's environment:

```env
PAYAI_API_KEY_ID=your-key-id
PAYAI_API_KEY_SECRET=your-key-secret
```

If you use `@payai/facilitator` (as the TypeScript server guides do), it reads these variables automatically. No code changes are needed. For other languages, see [facilitator authentication](/x402/facilitators/authentication).

```typescript
import { facilitator } from "@payai/facilitator";
import { HTTPFacilitatorClient } from "@x402/core/server";

// Automatically uses API keys from environment when available
const facilitatorClient = new HTTPFacilitatorClient(facilitator);
```

<Note>
  Free credits are tracked per receiving wallet, and per account when you use an API key. Very high-volume shared hosts may be asked to use an API key sooner.
</Note>
