<Warning>
  **New pricing takes effect on 21 September 2026 at 12:00 UTC.** From that moment each
  settlement is priced at the network's on-chain gas cost plus 30%, refreshed daily, and
  testnet settlements are free. Credits stay at **$0.001 each**. Until then every settlement
  costs 1 credit, as it does today. The live rate table — including any announced change —
  is always at
  [facilitator.payai.network/pricing](https://facilitator.payai.network/pricing).

## Free Credits

Ordinary exact payments can start within the free allowance below.

<Card title="Free" icon="gift">
  **$0/month**

  - **1,000 free credits per receiving wallet (lifetime)** — roughly 750 Solana or 470 Base
    settlements at the rates below
  - No API key required for ordinary exact payments
  - Testnet settlements are free and do not consume the allowance
</Card>

<Note>
  Free credits are counted per receiving wallet. Requests from shared hosts or IP
  addresses (e.g. shared cloud platforms) also draw from a shared pool, so those
  deployments may reach the limit sooner — create a merchant account and top up
  credits before reaching the applicable limit. Some older receiving wallets retain
  a legacy allowance of 10,000 credits; the 1,000-credit figure is the current
  default for new wallets, not a monthly reset. Settlements made before 21 September
  2026 count as 1 credit each toward the allowance.
</Note>

Get started immediately with zero setup. Jump to the [quickstart](/x402/quickstart) to start building.

<Note>
  [Solana batch settlement](/x402/servers/batch-settlement) requires a merchant API key from the first facilitator call. The free allowance is separate from portal credits and ATA setup costs.
</Note>

## Beyond the Free Credits

Beyond the free allowance, each settlement costs the facilitator's **on-chain gas for that
network plus 30%**, paid in credits:

<Card title="Cost-plus, per settlement" icon="coins">
  **price = network gas cost × 1.30**, converted to credits at $0.001 per credit and rounded
  up to the nearest 0.01 credit
</Card>

The facilitator measures what it actually pays in gas on each network and recomputes the
rates daily from the current gas and native-token prices. A rate is republished only when it
moves by more than 5%. Testnets are always 0.

<Note>
  The facilitator fee is separate from the price your API charges its customer.
  Payment amounts must satisfy the advertised payment requirements and the
  selected scheme's rules. Batch channel deposits have their own
  [limits](/x402/servers/batch-settlement); they are not the price of each API request.
</Note>

### Reading the live table

`GET https://facilitator.payai.network/pricing` returns the current rates and any
upcoming change with its effective time. `GET /supported` carries the same object under
`pricing`, so a server can read the price for the network it is about to use.

```json
{
  "creditUsd": "0.001",
  "marginBps": 3000,
  "rates": [
    { "network": "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp", "scheme": "exact",
      "transferMethod": "svm_transfer", "credits": "1.33", "usd": "0.00133",
      "effectiveAt": "2026-09-21T12:00:00.000Z" }
  ],
  "upcoming": []
}
```

## Credit System

To maintain access beyond the free allowance, merchants log into a dashboard and top up credits.

- **1 credit = $0.001**; a settlement debits its network's rate in credits (fractional credits are normal)
- **Credits never expire**

The merchant portal currently applies a **10% discount** when buying credits with
`$PAYAI` on Solana. Review the displayed quote before paying. This credit-purchase
discount is separate from the token and price your service accepts from its
customers; customers do not need `$PAYAI` to use an API priced in USDC.

<Card

  Log in to the merchant dashboard to manage your credits.
</Card>

Enterprise (invoiced) accounts are billed at the same rate card unless their agreement
sets a different margin.

## How to get started

1. Follow the [quickstart](/x402/quickstart) for ordinary exact payments without an API key, or the [batch guide](/x402/servers/batch-settlement) for authenticated metered payments
2. When you're ready to scale beyond the free allowance, create a merchant account at [merchant.payai.network](https://merchant.payai.network)
3. Top up credits from the dashboard
4. Get your API key ID and secret
5. Set the environment variables in your server:

```env
PAYAI_API_KEY_ID=your-key-id
PAYAI_API_KEY_SECRET=your-key-secret
```

If you're using `@payai/facilitator` (used throughout the TypeScript server guides), your server will automatically authenticate with the facilitator — no code changes needed.

```typescript
import { facilitator } from "@payai/facilitator";
import { HTTPFacilitatorClient } from "@x402/core/server";

// Automatically uses API keys from environment when available
const facilitatorClient = new HTTPFacilitatorClient(facilitator);
```

<Note>
  Rates track the chains' gas and token prices and are refreshed daily; material changes
  are announced ahead of their effective time on the live table. Visit
  [facilitator.payai.network/pricing](https://facilitator.payai.network/pricing) for the
  latest figures.
</Note>
