## Free Tier

Ordinary exact payments can start within the free allowance below.

<Card title="Free" icon="gift">
  **$0/month**

  - Up to **1,000 free settlements per receiving wallet (lifetime)**
  - No API key required for ordinary exact payments
</Card>

<Note>
  Free settlements are counted per receiving wallet. Requests from shared hosts or
  IP addresses (e.g. shared cloud platforms) also draw from a shared pool, so those
  deployments may reach the limit sooner — create a merchant account and top up
  credits before reaching the applicable limit. Some older receiving wallets
  retain a legacy allowance; the 1,000-settlement figure is the current default
  for new wallets, not a monthly reset.
</Note>

Get started immediately with zero setup. Jump to the [quickstart](/x402/quickstart) to start building.

<Note>
  [Solana batch settlement](/x402/servers/batch-settlement) requires a merchant API key from the first facilitator call. The free settlement allowance is separate from portal credits and ATA setup costs.
</Note>

## Beyond the Free Tier

Beyond the free tier, pricing is simple and predictable:

<Card title="Per Transaction" icon="coins">
  **$0.001 per transaction**
</Card>

<Note>
  The facilitator fee is separate from the price your API charges its customer.
  Payment amounts must satisfy the advertised payment requirements and the
  selected scheme's rules. Batch channel deposits have their own
  [limits](/x402/servers/batch-settlement); they are not the price of each API request.
</Note>

This fee is designed to cover gas and RPC costs while enabling the network to scale reliably.

### Builder friendly

The per-settlement fee makes facilitator costs predictable. Compare it with your
own gas, RPC and operational costs for the networks and traffic you plan to use;
self-hosting costs vary.

### Pricing examples

| Transactions | Cost |
|-------------|------|
| 1 | $0.001 |
| 1,000 | $1 |
| 100,000 | $100 |

## Credit System

To maintain access beyond the free tier, merchants log into a dashboard and top up credits.

- **1 credit = 1 settled transaction**
- **Credits never expire**

The merchant portal currently applies a **10% discount when buying credits with
$PAYAI on Solana**. Review the displayed quote before paying. This credit-purchase
discount is separate from the token and price your service accepts from its
customers; customers do not need $PAYAI to use an API priced in USDC.

## How to get started

1. Follow the [quickstart](/x402/quickstart) for ordinary exact payments without an API key, or the [batch guide](/x402/servers/batch-settlement) for authenticated metered payments
2. When you're ready to scale beyond the free tier, create a merchant account at [merchant.payai.network](https://merchant.payai.network)
3. Top up credits from the dashboard
4. Get your API key ID and secret
5. Set the environment variables in your server:

```env
PAYAI_API_KEY_ID=your-key-id
PAYAI_API_KEY_SECRET=your-key-secret
```

If you're using `@payai/facilitator` (used throughout the TypeScript server guides), your server will automatically authenticate with the facilitator — no code changes needed.

```typescript
import { facilitator } from "@payai/facilitator";
import { HTTPFacilitatorClient } from "@x402/core/server";

// Automatically uses API keys from environment when available
const facilitatorClient = new HTTPFacilitatorClient(facilitator);
```

<Note>
  Pricing is subject to change as PayAI continues to grow and adoption increases. For now, the focus is on sustainability at scale and building long-term value. Visit [facilitator.payai.network](https://facilitator.payai.network) for the latest pricing information.
</Note>
